# Core Concepts

OpenCommit is built around a small set of concepts.

- **Protocols** describe public-service processes as versioned, governed structures.
- **Commitments** are the institutionally meaningful actions created inside protocols.
- **Gates** define the checks that must be satisfied before an action can be treated as valid.
- **Receipts** record what happened, under which protocol version, with what authority, evidence, outcome, and recourse.
- **Conformance** defines what validators, packages, registries, runtime systems, and AI-assisted tools must support.
- **Civic agents** are AI-enabled or software-mediated actors that help people and institutions navigate public processes without becoming hidden authorities.

The conceptual distinction matters:

> Protocols are the reusable public processes. Commitments are the accountable actions they create. Receipts are the trust mechanism that lets others verify and rely on them.
