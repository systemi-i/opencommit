# Decision Records

Architecture decision records document choices that materially shape the ICSL v0.1 candidate. They preserve the problem considered, the decision taken, and its consequences for implementations and future versions.

An accepted ADR explains the design but does not replace normative specification text. Where an ADR and the candidate specification conflict, the specification governs and the inconsistency should be reported.
