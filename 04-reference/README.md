# Technical Reference

This section contains reference materials for implementers and technical reviewers.

It includes:

- a protocol-assessment method for source fidelity, representability, and candidate conformance;
- a copy-ready operating brief for protocol-review agents;
- JSON schemas for core ICSL objects;
- the candidate rule catalog;
- canonicalization notes;
- conformance suite guidance.

Use the [Protocol Assessment Guide](protocol-assessment-guide.md) to structure a review of a real institutional process. Give the [Agent Protocol-Alignment Brief](agent-protocol-alignment-brief.md) to an agent together with the protocol sources, any existing encoding, and the target conformance class.

The reference materials are part of the v0.1 candidate review package. They are intended to make the specification testable and implementable, not to imply final certification status.
