# Rule Catalog

The candidate rule catalog defines diagnostic identifiers used by the ICSL v0.1 harness and conformance suite.

The machine-readable catalog is available at:

[catalog.json](rules/catalog.json)

The catalog currently covers rules for:

- required commitment points;
- six-gate completeness;
- binding effect;
- advisory and shadow-binding semantics;
- recourse requirements;
- package manifest validity;
- hash vectors;
- conformance declarations;
- reference versions;
- rendering boundaries;
- runtime binding smuggling;
- AI authority boundaries;
- durable evidence;
- dependency references;
- version pinning;
- governance addenda.

The rule catalog is candidate-stage and expected to evolve through public review.
