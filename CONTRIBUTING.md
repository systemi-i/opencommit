# Contributing

OpenCommit is currently in candidate review.

Contributions should help improve the clarity, implementability, institutional realism, and safety of the ICSL v0.1 candidate.

Useful contributions include:

- conceptual issues;
- specification edits;
- schema corrections;
- fixture additions;
- conformance-rule improvements;
- implementation notes;
- domain examples;
- governance, recourse, and authority critiques;
- AI boundary and civic-agent reviews.

Please identify whether an issue is:

- a blocker for v0.1;
- a clarification needed before public release;
- a candidate implementation issue;
- a later roadmap item.

Do not describe any current implementation as finally certified or fully ICSL-compliant. Use candidate-stage language until a public standard and certification process are finalized.
