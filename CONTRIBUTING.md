# Contributing

OpenCommit is currently in candidate review.

Contributions should help improve the clarity, implementability, institutional realism, and safety of the ICSL v0.1 candidate.

Useful contributions include:

- conceptual issues;
- specification edits;
- schema corrections;
- fixture additions;
- conformance-rule improvements;
- implementation notes;
- domain examples;
- governance, recourse, and authority critiques;
- AI boundary and civic-agent reviews.

## Where to Contribute

File contributions and feedback as GitHub issues at <https://github.com/systemi-i/opencommit/issues>.

## Severity

Please assign each issue one of the severities from the [Feedback Intake Guide](05-public-review/feedback-intake-guide.md):

- Blocking
- Important
- Improvement
- Clarification
- Future

Do not describe any current implementation as finally certified or fully ICSL-compliant. Use candidate-stage language until a public standard and certification process are finalized.

## License and Developer Certificate of Origin

- Contributions to prose, specifications, and review materials are accepted under CC BY 4.0 (see [LICENSE](LICENSE)).
- Contributions to JSON schemas, the rule catalog, and future fixtures are accepted under Apache-2.0 (see [LICENSE-APACHE](LICENSE-APACHE)).
- Contributors certify their contributions under the [Developer Certificate of Origin (DCO) 1.1](https://developercertificate.org/) by adding a `Signed-off-by:` line to each commit (`git commit --signoff`).
