# Stewardship

## Current Steward

The ICSL v0.1 candidate and related OpenCommit project materials are published and stewarded by Intelligent Institutions Lab, operator of `igsl.dev`.

## Change Process

- Spec editors decide which proposed changes are accepted into the candidate specification.
- Accepted decisions are logged as decision records in [07-decisions/](07-decisions/README.md).
- Feedback enters through GitHub issues at <https://github.com/systemi-i/opencommit/issues>, triaged per the [Feedback Intake Guide](05-public-review/feedback-intake-guide.md).
- Escalations from the feedback-intake process go to the spec editors via GitHub issues labeled `escalation`.

## Names and Namespaces

The steward asserts stewardship of:

- the ICSL name;
- the `igsl.dev` schema `$id` namespace (`https://igsl.dev/icsl/schemas/...`);
- conformance class names;
- test-suite identifiers.

ICSL is the public identity of the standard and consultation. OpenCommit is a
non-normative project and stewardship name; it does not appear in canonical ICSL
artifacts, namespaces, conformance classes, or version identifiers.

## Standards Home

The long-term standards home and governance structure remain open. The steward intends to move ICSL toward a neutral, multi-stakeholder venue if implementation and consultation establish sufficient interest. No affiliation with an external standards body is currently claimed.
